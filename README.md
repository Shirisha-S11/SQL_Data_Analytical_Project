# SQL_Data_Analytical_Project
Chocolate Sales Analysis Project This project uses SQL to analyze a chocolate sales dataset, focusing on sales performance across products, teams, and geographic regions. It demonstrates key SQL skills such as joins, aggregations, filtering, and conditional logic to generate meaningful business insights.

## 📌 Project Overview

This repository contains a set of SQL queries used to analyze a chocolate sales dataset.  
It includes examples of basic SELECTs, joins, aggregations, and conditional logic that demonstrate practical SQL skills for data exploration and reporting.

---

## 📁 Repository Contents

| File | Description |
|------|-------------|
| `Basics.sql` | Simple selection and filtering queries |
| `Joins.sql` | Examples of joining multiple tables |
| `Aggregate functions.sql` | Aggregation queries (SUM, AVG, GROUP BY) |
| `Problems.sql` | More advanced analytical queries |
| `A_Choclate-data.sql` | SQL to create or load the dataset (schema & inserts) |
| `README.md` | Project documentation |

## 🚀 What You’ll Find

### 1. **Basic SQL Queries**
- Selecting records
- Filtering with `WHERE`
- Using conditional logic

### 2. **Join Operations**
- Combining tables using `JOIN` to associate sales with people, products, and geography

### 3. **Aggregate Analysis**
- Computing totals (SUM)
- Averages (AVG)
- Grouping by categories or geographic regions

### 4. **Conditional Columns**
- Using `CASE` statements to label data (e.g., flagging Wednesday shipments)

These examples help demonstrate skills useful in data analyst roles, such as writing business-oriented SQL reports.
